Repositório criado para a entrega dos exercícios de fixação sobre Listas, ListView e Cards em Flutter, desenvolvidos utilizando os conceitos fundamentais estudados até o momento.

## 📂 Estrutura dos Exercícios
O repositório está organizado em pastas individuais para cada exercício da lista:

- **exercicio01/**: Lista de linguagens de programação com `List<String>` e `ListView.builder`
- **exercicio02/**: Catálogo de livros com classe `Livro` exibida em `Card` e `ListTile`
- **exercicio03/**: Lista de alunos com classe `Aluno` (nome e nota)
- **exercicio04/**: Cadastro dinâmico de tarefas com adição e remoção via `IconButton`
- **exercicio05/**: Controle de estoque de produtos com cadastro, remoção e validação de campos vazios
